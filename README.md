## About this Package?

The **Screenshots tool** is a versatile system for capturing high-quality images of your game or Unity Editor content - perfect for **marketing**, **documentation**, or **development**.

It supports **LWRP**, **URP**, and **HDRP** pipelines and provides multiple capture methods directly in the Unity Editor.

## Features

✔️ **Window Capture** - pixel-perfect screenshots of any Editor window, including custom tools and the inspector    
✔️ **Camera Capture** - attach to any in-game camera for runtime or scene captures    
✔️ **Customizable output** - resolution, image depth, background overrides (transparent, solid, or custom)    
✔️ **Icon generation** - create ready-to-use game item icons inside Unity using the versatile settings    
✔️ **Postprocessing support** - compatible with Unity’s post-processing system    
✔️ **Hotkey capture** - define a key to take screenshots instantly, even during play mode    
✔️ **Multi-camera support** - capture multiple angles simultaneously for trailers, social media, or documentation
